# Agent Workspace

This directory is reserved for tool-neutral agent support material.

Active instructions remain in `AGENTS.md` files:

- `AGENTS.md` at the repository root for project-wide rules.
- `firmware/AGENTS.md` for firmware-specific rules.
- `gui/EscGui/AGENTS.md` for GUI and bridge-specific rules.

Do not duplicate active guidance into model-specific mirrors such as `CLAUDE.md`.
Do not commit local tool runtime configuration under `.codex/`; keep that local to each developer environment.
